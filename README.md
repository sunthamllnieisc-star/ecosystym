# EcoVis Grassland

A browser game where you sculpt a little 3D planet and grow a meadow around it.

Open `index.html` in a browser with WebGL 2. No build or install is required.

- Drag the planet to rotate. Scroll or pinch to zoom.
- Select **Raise** and drag from the pale ring to sculpt a ridge.
- Continue to **Sow**, then paint grass around the planet. Switch to **Rotate** to reach the other side.

This project bundles Three.js. See [its license](vendor/THREE-LICENSE.txt).
